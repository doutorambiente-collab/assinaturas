# Assinaturas de e-mail

Imagens das assinaturas de e-mail, servidas pelo jsDelivr.

- `dinamica/`: assinatura do Aroldo na Dinâmica Ambiental.
  - Endereço das imagens: `https://cdn.jsdelivr.net/gh/doutorambiente-collab/assinaturas@v1/dinamica/<arquivo>.png`
  - `assinatura-aroldo.html`: o HTML para colar no Gmail.

Para mudar uma imagem, suba a nova e crie uma tag nova (`v2`). Os e-mails já enviados continuam apontando para a `v1` e não quebram.
