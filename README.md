# Assinaturas de e-mail

Imagens das assinaturas de e-mail, servidas pelo jsDelivr.

- `dinamica/`: assinatura do Aroldo na Dinâmica Ambiental.
  - Endereço das imagens: `https://cdn.jsdelivr.net/gh/doutorambiente-collab/assinaturas@e458fcc586d40980dfcfd2d7b0463ab17ee2d5d4/dinamica/<arquivo>.png`
  - `assinatura-aroldo.html`: o HTML para colar no Gmail.

O endereço aponta para um commit fixo, que nunca muda: os e-mails já enviados não quebram. Para trocar uma imagem, suba a nova e atualize o HTML com o código do novo commit.
